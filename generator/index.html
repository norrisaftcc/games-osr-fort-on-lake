How it works

The lesson ladder is fixed. The content is rolled. Each template has a list of lessons in a fixed order. The engine builds a map so that each lesson sits deeper than the one before it, then fills every room from the tables. A seed is the starting number for the dice. Same seed, same tables: same dungeon.

  1. Add a table entry. Open generator/tables.js. Find a list, such as ForgeTables.tower.cellarFiller or ForgeTables.ravine.quirks. Copy an entry, change its words, save, and reload this page. Read-aloud text is one or two short sentences. Changing a table changes what a seed makes.
  2. Change a rule. The lesson ladders are in TEMPLATES near the top of generator/forge.js. Their order is the point of the dungeon. Change it only on purpose.
  3. Write a new template. In forge.js, write a genSomething(seed, level) that returns rooms with keys, exits and map boxes, add its lessons to TEMPLATES, and list it in GENERATORS. Then run node generator/test.mjs: it checks hundreds of seeds for you.
